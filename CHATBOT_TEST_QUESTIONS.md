1. Open the chatbot widget in your app
2. Copy one question from above
3. Paste into chatbot input
4. Verify response makes sense
5. Check if numbers are personalized

### Option 2: Automated Test Script
```bash
# Test a single question
curl -X POST http://localhost:8080/api/chatbot/ask \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -d '{"message":"Quel est mon solde de congés?"}'

# Response should include your actual leave balance
```
